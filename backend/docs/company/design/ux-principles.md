# UX 원칙

## 목적
일관되고 사용자 중심적인 경험을 만들기 위한 디자인 판단 기준이다. 의견이 갈릴 때 본 원칙으로 결정한다.

## 핵심 원칙
1. 명확성 우선: 화려함보다 이해하기 쉬운 것을 택한다.
2. 사용자 통제: 사용자가 흐름을 주도하고 되돌릴 수 있게 한다.
3. 일관성: 같은 동작은 같은 방식으로 작동한다.
4. 즉각적 피드백: 모든 동작에 명확한 반응을 준다.
5. 오류 방지: 실수하기 어렵게 설계하고, 실수해도 복구하기 쉽게 한다.

## 적용 가이드
- 핵심 작업은 3클릭 이내에 도달하도록 한다.
- 빈 화면(empty state)에도 다음 행동을 안내한다.
- 로딩·에러·성공 상태를 모두 설계한다.
- 모바일·데스크톱 모두에서 동작을 검증한다.

## 콘텐츠
- 사용자의 언어로 쓴다(내부 용어 지양).
- 버튼·링크 문구는 결과를 명확히 드러낸다(예: "삭제" vs "확인").

## 검증
디자인은 사용성 테스트로 검증하고, 출시 후 행동 데이터로 가설을 확인한다. 데이터와 원칙이 충돌하면 데이터를 우선하되 원칙을 재검토한다.
