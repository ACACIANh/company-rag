2-tier 접근 권한 제어

OpenFGA (ABAC) + ChromaDB Pre-filter — 비인가 문서 노출 0건

1
사용자 컨텍스트 추출

로그인 세션에서 user_id, team_id, sensitivity_level을 추출. 모든 검색 요청에 자동 첨부됨.

인증 레이어
2
1st Tier — Chroma 메타데이터 Pre-filter

벡터 검색 전에 team_id + sensitivity 조건으로 후보 집합을 필터링. LLM 호출 없이 결정론적으로 수행. 전체 문서 목록 순회 없이 O(1).

ChromaDB where 절
3
2nd Tier — OpenFGA ABAC 검증

개인 문서 ID에 대해 OpenFGA로 세밀한 권한 확인. listObjects 전체 조회 없이 check(user, doc_id) 방식으로 성능 보장.

ABAC / RBAC
4
PostgreSQL TTL 캐시

FGA 검증 결과를 기존 PostgreSQL 인프라에 TTL 캐시. Redis 추가 없이 재사용 — 인프라 복잡도 최소화.

기존 PG 재사용
