Retrieval Metrics

검색 성능 지표

📊 Recall@K
검색된 정답 수 / 전체 정답 수

상위 K개 결과에 정답 문서가 포함된 비율. 필요한 정보를 놓치지 않는지 측정합니다.

def recall_at_k(retrieved_ids, relevant_ids, k):
    retrieved_set = set(retrieved_ids[:k])
    relevant_set  = set(relevant_ids)
    return len(retrieved_set & relevant_set) / len(relevant_set)
🎯 Precision@K
정답 문서 수 / K

상위 K개 결과 중 실제 정답 문서의 비율. 노이즈 문서가 얼마나 끼어드는지 진단합니다.

🏅 MRR (Mean Reciprocal Rank)
1 / rank of first correct answer

첫 번째 정답 문서의 순위 역수 평균. 정답이 얼마나 상위에 있는지를 측정합니다.

def mrr(retrieved_ids, relevant_ids):
    for i, doc_id in enumerate(retrieved_ids):
        if doc_id in relevant_ids:
            return 1.0 / (i + 1)
    return 0.0
📈 NDCG & Hit Rate
DCG / Ideal DCG  |  성공 쿼리 / 전체 쿼리

NDCG: 순위를 고려한 검색 품질 점수. 높은 순위 정답에 더 큰 가중치를 줍니다.
Hit Rate: 정답 문서가 하나라도 포함된 쿼리의 비율. 가장 단순한 성공 지표.

Generation Metrics

생성 품질 지표

✅ Faithfulness (충실도)

답변이 컨텍스트에 근거하는 정도. LLM-as-Judge로 각 문장의 출처를 검증합니다.

💬 Answer Relevancy (답변 관련성)

답변이 질문에 적절한 정도. 답변에서 역으로 질문을 생성한 뒤 원래 질문과 유사도를 비교합니다.

📄 Context Relevancy (컨텍스트 관련성)

검색된 컨텍스트가 질문에 관련된 정도. 컨텍스트 내 관련 문장의 비율로 측정합니다.

👻 Hallucination Rate (환각률)

컨텍스트에 없는 정보를 생성한 비율. 답변 내 비근거 정보를 탐지하여 산출합니다.

Failure Patterns

주요 실패 패턴 6가지

1

잘못된 청크 검색 (Retrieval Failure)

심각도: 매우 높음
증상 예시 — "2024년 4분기 매출"을 질문했는데 2023년 데이터가 반환됨
원인
  • 고정 길이 청킹으로 문맥 분리
  • 임베딩 모델의 도메인 불일치
  • 메타데이터 필터링 부재
해결 방향
  • 메타데이터 필터(연도, 분기) 적용
  • Semantic Chunker 도입
  • 도메인 전용 임베딩 모델 사용
# 메타데이터 필터를 활용한 검색
results = vectorstore.similarity_search(
    query="4분기 매출",
    filter={"year": 2024, "quarter": "Q4"},
    k=5
)

2

컨텍스트 윈도우 오버플로우

심각도: 높음
너무 많이 검색 시
  • 토큰 제한 초과로 컨텍스트 잘림
  • 노이즈 문서가 LLM 주의 분산
  • API 비용 증가
너무 적게 검색 시
  • 답변 필요 정보 부족
  • 불완전하거나 오류 있는 답변
def adaptive_retrieval(query, retriever, min_k=3, max_k=10, threshold=0.7):
    """유사도 임계값 기반으로 동적 K 조절"""
    results = retriever.similarity_search_with_score(query, k=max_k)

    filtered = [
        (doc, score) for doc, score in results
        if score >= threshold
    ]

    if len(filtered) < min_k:
        return [doc for doc, _ in results[:min_k]]

    return [doc for doc, _ in filtered]
3

올바른 검색에도 불구한 환각 (Hallucination)

심각도: 매우 높음
원인
  • LLM 사전 학습 지식이 컨텍스트와 충돌
  • 프롬프트에 "컨텍스트만 사용" 지시 불충분
  • 부분 정보에서 LLM이 나머지를 추측하여 채움
해결 방향
  • 엄격한 출처 표시 프롬프트 적용
  • Faithfulness 지표로 자동 탐지
  • "모르면 모른다고" 답변 규칙 명시
ANTI_HALLUCINATION_PROMPT = """당신은 주어진 컨텍스트만을 기반으로 답변하는 어시스턴트입니다.

규칙:
1. 반드시 컨텍스트에 있는 정보만 사용하세요.
2. 컨텍스트에 없는 정보는 "제공된 문서에서 해당 정보를 찾을 수 없습니다"라고 답하세요.
3. 추측하거나 사전 지식을 사용하지 마세요.
4. 답변의 각 문장 끝에 [출처: 문서N]을 표시하세요.

컨텍스트:
{context}

질문: {question}

답변:"""
4

Lost-in-the-Middle 문제

심각도: 중간
증상 — LLM이 긴 컨텍스트의 중간에 위치한 정보를 효과적으로 활용하지 못함. 검색 문서가 많을수록 심화됨.
원인
  • 컨텍스트 시작·끝은 잘 활용
  • 중간 정보는 무시되거나 놓침
해결 방향
  • 중요 문서를 시작·끝에 재배치
  • 검색 수(K) 최소화
def reorder_for_lost_in_middle(documents, scores):
    """가장 관련성 높은 문서를 시작과 끝에 배치"""
    sorted_docs = sorted(
        zip(documents, scores), key=lambda x: x[1], reverse=True
    )
    reordered = []
    for i, (doc, score) in enumerate(sorted_docs):
        if i % 2 == 0:
            reordered.insert(0, doc)  # 앞에 삽입
        else:
            reordered.append(doc)       # 뒤에 삽입
    return reordered

심각도: 중간

오래된 지식 베이스 (Stale Knowledge Base)

심각도: 높음
증상 — 지식 베이스 문서가 최신 정보를 반영하지 못해 사용자에게 구식 답변 제공 
class KnowledgeBaseFreshnessManager:
    def __init__(self, vectorstore, max_age_days=30):
        self.vectorstore = vectorstore
        self.max_age_days = max_age_days

    def check_staleness(self):
        """오래된 문서 탐지"""
        cutoff = datetime.now() - timedelta(days=self.max_age_days)
        return self.vectorstore.query(
            filter={"updated_at": {"$lt": cutoff.isoformat()}}
        )

    def add_temporal_boost(self, results, recency_weight=0.1):
        """최신 문서에 가산점 부여"""
        now = datetime.now()
        boosted = []
        for doc, score in results:
            age_days = (now - doc.metadata["updated_at"]).days
            recency_score = max(0, 1 - age_days / 365)
            final_score = score + recency_weight * recency_score
            boosted.append((doc, final_score))
        return sorted(boosted, key=lambda x: x[1], reverse=True)
