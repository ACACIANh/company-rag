# 피처 플래그

## 목적
피처 플래그를 사용해 기능을 코드 배포와 분리하여 제어한다. 이를 통해 점진적 롤아웃, 빠른 비활성화, A/B 테스트가 가능하다.

## 플래그 종류
- 릴리스 플래그: 미완성 기능을 숨긴 채 배포
- 운영 플래그: 부하 상황에서 기능을 끄기 위한 스위치
- 실험 플래그: A/B 테스트용 분기
- 권한 플래그: 특정 그룹에만 기능 노출

## 점진적 롤아웃 절차
1. 내부 직원에게만 노출(0% → 사내)
2. 베타 사용자 5%에 롤아웃
3. 지표 확인 후 25% → 50% → 100%로 단계적 확대
4. 각 단계에서 에러율·핵심 지표 모니터링
5. 이상 발생 시 즉시 0%로 롤백

## 운영 원칙
- 모든 플래그에는 담당자와 만료일을 지정한다.
- 100% 롤아웃 후 안정화되면 플래그와 죽은 코드를 제거한다.
- 장기 방치된 플래그는 분기마다 정리한다.

## 관리 도구
플래그는 중앙 플래그 관리 콘솔(flags.techcorp.example)에서 설정하며, 변경 이력은 자동 기록된다.
