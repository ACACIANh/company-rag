# 회의 문화

## 회의 원칙
- 목적 없는 회의는 잡지 않는다
- 30분 기본, 1시간은 예외적으로
- 결론과 액션 아이템이 없으면 회의가 아니다

## 회의 전 준비
- 애전다 24시간 전 공유
- 자료는 회의 1시간 전까지 공유
- 불필요한 참석자는 초대하지 않는다

## 회의 중 규칙
- 시작 시간 엄수 (5분 이상 지각 = 1,000원 벌금 → 팀 간식비)
- 휴대폰은 무음 모드
- 발언 기회는 모두에게

## 회의록 작성
- 결론과 액션 아이템 반드시 기록
- 담당자와 기한 명시
- 회의 종료 24시간 이내 Confluence에 올리기

## 비동기 우선 문화
- 긴급하지 않은 사안은 Slack 또는 Jira로 비동기 처리
- 회의로 결정해야 할 것: 복잡한 트레이드오프, 갈등 해소
- 회의가 필요 없는 것: 상태 공유, 단순 정보 전달
