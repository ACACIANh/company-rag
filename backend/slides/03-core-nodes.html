핵심 노드 구성

app/graph/nodes/ — 순수 함수로 구현, State in → State out

🔀
router

질문을 분석해 doc_search / tool_call / web_search 세 경로로 분기. LLM 기반 의도 분류.

라우팅
🔍
retrieve

ChromaDB 벡터 검색 + BM25 키워드 검색을 결합한 Hybrid 검색. LLM Reranker로 top-5 선별.

검색
⚖️
grade_documents

검색된 문서의 관련성을 LLM이 채점. 점수 미달 시 질문 재작성으로 Self-RAG 루프 진입.

평가
💡
generate

관련 문서를 컨텍스트로 주입해 Claude / GPT-4o로 답변 생성. 출처 인용 포함, 스트리밍 지원.

생성
🛡️
check_hallucination

생성된 답변이 검색된 문서에 근거를 두는지 LLM이 검증. 근거 부족 시 재생성 트리거.

가드레일
🧠
load_memory / save_memory

MemorySaver 체크포인터로 대화 이력 유지. 최근 10턴 트리밍으로 토큰 폭증 방지.
