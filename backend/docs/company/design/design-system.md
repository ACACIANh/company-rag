# 디자인 시스템

## 목적
일관된 사용자 경험과 빠른 개발을 위해 디자인 시스템을 운영한다. 디자이너와 개발자가 동일한 컴포넌트와 디자인 토큰을 공유한다.

## 구성 요소
- 디자인 토큰: 색상·간격·타이포·그림자 등 기본 값
- 컴포넌트 라이브러리: 재사용 가능한 UI 컴포넌트 모음
- 패턴: 폼·테이블·모달 등 화면 조합 가이드
- 문서: 사용법과 예시

## 디자인 토큰
- 컬러 토큰: primary, secondary, success, warning, danger, neutral
- 간격 토큰: 4px 배수 기반 스케일(4, 8, 12, 16, 24, 32)
- 타이포 토큰: 글꼴·크기·굵기·행간 정의
- 토큰은 Figma와 코드에서 단일 소스로 동기화한다.

## 컴포넌트 라이브러리
- Button, Input, Select, Modal, Toast, Table 등 기본 컴포넌트 제공
- 각 컴포넌트는 상태(기본·호버·비활성·에러)를 정의
- 접근성 기준을 충족하도록 구현
- Storybook으로 컴포넌트 카탈로그 관리

## 기여 절차
1. 신규 컴포넌트 제안서 작성
2. 디자인·프론트엔드 리뷰
3. 토큰·접근성 검토
4. 라이브러리에 추가 및 문서화

## 버전 관리
디자인 시스템은 시맨틱 버저닝을 따르며, 변경 시 마이그레이션 가이드를 함께 제공한다.
