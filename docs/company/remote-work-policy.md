# 재택근무 정책

## 기본 원칙
주 3일 출근, 주 2일 재택을 기본으로 한다. 팀별 협의로 조정 가능.

## 재택근무 가능 조건
- 입사 수습 기간(3개월) 종료 후 가능
- 팀장 사전 승인 필요 (HR 시스템에서 신청)
- 코어타임(10:00~17:00) 동안 화상/메시지 응대 가능해야 함

## 재택 시 필수 사항
- 화상회의 참석 시 카메라 켜기 (선택이지만 권장)
- Slack 상태 업데이트 (재택 중)
- 업무 시작/종료 시 팀 채널에 공지
- VPN 연결 후 사내 시스템 접속

## 재택 불가 날짜
- 전사 워크숍
- 팀 정기 미팅 주간 (분기별 1회, 일정 별도 공지)
- 중요 데모 또는 발표 일정

## 해외 원격 근무
- 최대 연 30일 허용 (팀장 + 인사팀 승인)
- 국가별 세금/법인 이슈로 일부 국가 제한 있음 (인사팀 확인)
