# 성과 평가 제도

## 평가 주기
- 반기 평가: 6월 말, 12월 말
- 연간 성과급 반영: 12월 평가 기준

## 평가 항목
1. 목표 달성도 (40%): 분기 초 합의한 OKR 기준
2. 역량 (30%): 기술 역량 + 협업 + 의사소통
3. 기여도 (20%): 팀/조직 기여 (코드 리뷰, 문서화, 멘토링 등)
4. 성장성 (10%): 자기계발 노력

## 평가 등급
- S: 탁월 (상위 10%)
- A: 우수 (상위 30%)
- B: 양호 (중간 50%)
- C: 개선 필요 (하위 10%)

## 평가 프로세스
1. 자기 평가 작성 (HR 시스템)
2. 동료 피드백 수집 (360도 평가)
3. 팀장 평가 면담
4. 인사팀 조정 회의
5. 결과 통보 및 면담

## 성과급
- S 등급: 연봉의 15%
- A 등급: 연봉의 10%
- B 등급: 연봉의 5%
- C 등급: 없음 (PIP 대상)
