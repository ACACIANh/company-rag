AI 모델
OpenAI gpt-4.1-mini 기반. 다른 모델로 교체 가능한 구조로 비용·성능을 유연하게 조정.

접근 제어
OpenFGA로 폴더·테이블·개인 단위 권한 관리. 구글이 쓰는 권한 모델과 같은 방식.
🗃️
데이터 저장
PostgreSQL 하나로 업무 DB·캐시·문서 검색(pgvector)까지. 인프라 단순·안정.
🌐
서비스 형태
웹 화면(Vite) + 백엔드(FastAPI). 답변이 실시간으로 흘러나오는 스트리밍 방식.
