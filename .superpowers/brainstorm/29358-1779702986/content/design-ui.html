주요 동작

  • ☰ 버튼으로 사이드바 토글 — 기본은 열린 상태
  • 세션 클릭 시 해당 세션의 메시지 히스토리 전체 로드
  • 세션 제목 = 첫 질문 앞 20자 자동 생성
  • 날짜별 그룹 (오늘 / 어제 / 이번 주)
  • 🗑 아이콘: hover 시 표시, 클릭 시 삭제 확인 없이 즉시 삭제
  • 로그아웃 → 재로그인 후 세션 목록 완전 복원
