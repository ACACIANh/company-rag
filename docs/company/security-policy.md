# 정보 보안 정책

## 기본 원칙
- 최소 권한 원칙: 업무에 필요한 최소한의 권한만 부여
- 알 필요 원칙: 업무와 직접 관련된 정보에만 접근
- 기록의 원칙: 모든 접근 이력은 로그로 보관

## 패스워드 정책
- 최소 12자 이상
- 대문자, 소문자, 숫자, 특수문자 각 1개 이상 포함
- 90일마다 강제 변경
- 이전 5회 비밀번호 재사용 금지
- 사내 시스템은 모두 MFA 필수

## 기기 보안
- 자리 비울 때 화면 잠금 필수 (단축키: Win+L / Cmd+Ctrl+Q)
- 화면 보호기: 5분 후 자동 잠금
- 분실 즉시 IT팀에 신고 (내선 1234)
- 개인 USB 드라이브 사용 금지

## 데이터 분류
- 기밀(Confidential): 계약서, 재무정보, 개인정보
- 내부(Internal): 사내 문서, 회의록, 코드
- 공개(Public): 마케팅 자료, 채용 공고

## 외부 공유 금지 항목
- 미발표 제품 로드맵
- 고객 데이터 (익명화 없이)
- 직원 개인정보
- 소스 코드 (승인된 오픈소스 제외)
