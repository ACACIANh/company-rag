# CRM 운영 프로세스

## 목적
영업 데이터를 일관되게 관리하고 파이프라인을 투명하게 운영하기 위한 CRM 사용 규칙이다. 모든 영업 활동은 CRM에 기록한다.

## 파이프라인 단계
CRM의 거래(Deal) 단계는 영업 플레이북의 세일즈 단계와 일치한다.
- 리드 → 자격검증 → 디스커버리 → 제안 → 협상 → 체결 → 종료

## 입력 규칙
- 신규 리드는 24시간 이내 CRM에 등록한다.
- 모든 고객 접촉(콜·미팅·이메일)을 활동으로 기록한다.
- 거래 단계 이동 시 사유와 다음 액션을 남긴다.
- 예상 마감일과 예상 금액을 최신 상태로 유지한다.

## 파이프라인 관리
- 주간 파이프라인 리뷰에서 단계별 거래를 점검한다.
- 30일 이상 단계 변화가 없는 거래는 정체(stale)로 표시한다.
- 종료된 거래는 성공/실패 사유를 반드시 기록한다.

## 데이터 품질
- 중복 고객·연락처를 정기적으로 정리한다.
- 필수 필드 미입력 거래는 단계 진행을 제한한다.

## 리포팅
파이프라인 가치·전환율·예상 매출은 CRM 대시보드에서 자동 집계되며, 매월 영업 리포트에 반영된다.
