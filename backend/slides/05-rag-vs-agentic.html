항목
단순 RAG
Agentic RAG (이 프로젝트)
🔍 검색 방식
고정된 벡터 검색만 수행. 검색 실패 시 그냥 빈 답변 반환
→
doc_search / tool_call / web_search 3-way 자동 라우팅. 관련성 부족 시 질문 재작성 후 재검색
🧠 대화 메모리
매 질문이 독립적. "방금 그 문서 더 보여줘" 같은 참조 불가
→
MemorySaver 체크포인터로 멀티턴 컨텍스트 유지. 대명사·참조 표현 자동 해소
✅ 답변 품질
생성된 답변의 사실 여부를 검증하지 않음. 환각 그대로 노출
→
LLM Reranker (MRR +13%) + 환각 체크 노드로 이중 품질 보장
🔒 접근 권한
모든 사용자가 전체 문서에 접근 가능. 기밀 문서 노출 위험
→
OpenFGA 2-tier Pre-filter. 팀별·민감도별 문서 필터링 → 비인가 노출 0건
