# 장애 대응 가이드

## 심각도 등급
- P0: 전체 서비스 중단 또는 데이터 손실
- P1: 핵심 기능 장애 (결제, 로그인 등)
- P2: 일부 기능 장애 (대안 경로 존재)
- P3: 경미한 UI/UX 문제

## 초기 대응 (15분 이내)
1. 인시던트 채널 생성: #incident-YYYY-MM-DD
2. 인시던트 리더 지정
3. 영향 범위 파악 (사용자 수, 서비스 범위)
4. 임시 조치 (트래픽 차단, 롤백 등)

## 의사소통
- P0/P1: CEO, CTO에게 즉시 보고
- 외부 공지: 서비스 상태 페이지(status.acmecorp.com) 업데이트
- 고객 안내: 지원팀에 상황 공유

## 사후 처리 (48시간 이내)
- 포스트모템 문서 작성 (타임라인, 원인, 재발 방지책)
- Jira 티켓으로 재발 방지 액션 아이템 등록
- 팀 공유 (비난 없는 학습 문화)

## 온콜 담당자
온콜 로테이션: 1주 단위, PagerDuty로 알림.
