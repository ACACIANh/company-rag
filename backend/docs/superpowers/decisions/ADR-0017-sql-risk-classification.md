# ADR-0017: SQL 위험도 분류 — AST 확정 + LLM 보강

> **Status**: ⚪ 제안됨

**Date**: 2026-06-02
**Context**: [ADR-0016](ADR-0016-identity-risk-sql-gate.md)의 3-state 게이트는 SQL 위험도 등급(일반 SELECT / 대량·PII SELECT / UPDATE·DELETE / DDL)을 입력으로 받는다. 이 분류 노드가 게이트 전체의 **단일 실패점**이다. 위험도를 LLM에 통째로 위임하면 프롬프트 우회(예: `SELECT`로 위장한 서브쿼리, 주석 안에 숨긴 `DROP`)에 뚫린다.

## Options

| 선택지 | 트레이드오프 |
|--------|------------|
| LLM 단독 분류 | 구현 빠름·방언 무관. 그러나 우회에 취약, 결정 근거가 "AI가 판단함" 한 줄이라 방어력 0 |
| 정규식/키워드 매칭 | 의존성 0. 그러나 서브쿼리·CTE·중첩 구문을 못 잡고 오탐·미탐 양쪽으로 샘 |
| **AST 파서(sqlglot) 확정 + LLM 보강** | 구문 종류는 AST로 결정론적 확정(우회 차단), "대량/PII" 같은 의미 판단만 LLM이 보강. 신규 의존성·방언 커버리지 한계 |

## Decision

**선택: sqlglot AST로 구문 종류를 확정하고, 의미적 위험(대량·PII)만 LLM으로 보강한다.**

1. **AST 확정 (결정론)**: sqlglot으로 파싱해 최상위·서브쿼리·CTE를 포함한 모든 구문의 종류(SELECT/UPDATE/DELETE/DDL)를 추출한다. 하나라도 쓰기/DDL이 섞이면 그 등급으로 승급한다.
2. **LLM 보강 (의미)**: 순수 SELECT로 확정된 건에 한해, "풀스캔·PII 컬럼 포함" 여부를 LLM이 판정해 `대량 SELECT`로 승급할지 결정한다. LLM은 **등급을 낮추지 못한다**(상향만 가능).
3. **보수적 폴백**: 파싱 실패·미지원 방언·모호 구문은 **DENY**로 처리한다 (ADR-0016 매트릭스의 최고 위험 취급).

신규 의존성 **sqlglot**을 도입한다(DoD: 새 의존성 ADR — 본 문서가 그 기록).

## Rationale

- **구문 종류는 결정론적 사실**이므로 AST가 맞다. LLM은 사실 판정이 아니라 "대량/PII" 같은 회색 의미 판단에만 쓴다.
- **LLM은 상향만** 허용 → LLM을 속여 위험도를 낮추는 공격이 구조적으로 불가능하다.
- **미지원 구문 = DENY**: 커버리지 구멍을 안전한 방향으로 닫는다. sqlglot 방언 한계가 곧 권한 누수가 되지 않게 한다.

## 미해결 / 후속

- sqlglot 방언 설정(Postgres) 확정 및 미지원 구문 목록 회귀 테스트.
- "대량/PII" 판정 기준의 명세화(row 추정·PII 컬럼 사전) — LLM 프롬프트만으로 둘지, 메타데이터 기반으로 보강할지.
