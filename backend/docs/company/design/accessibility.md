# 접근성 기준

## 목적
모든 사용자가 제품을 동등하게 사용할 수 있도록 접근성 기준을 정의한다. 신규 화면은 본 기준을 충족해야 출시할 수 있다.

## 준수 표준
- WCAG 2.1 AA 수준을 기본 목표로 한다.
- 주요 화면은 AAA 수준을 지향한다.

## 색상과 대비
- 본문 텍스트 대비 비율 4.5:1 이상
- 큰 텍스트(18pt 이상) 대비 비율 3:1 이상
- 색상만으로 정보를 전달하지 않는다(아이콘·텍스트 병행).

## 키보드 접근성
- 모든 기능을 키보드만으로 사용할 수 있어야 한다.
- 포커스 순서가 논리적이어야 한다.
- 포커스 표시(focus ring)를 명확히 한다.

## 스크린리더
- 의미 있는 HTML 시맨틱 태그를 사용한다.
- 이미지에는 대체 텍스트(alt)를 제공한다.
- 폼 요소에는 레이블을 연결한다.
- 동적 변경은 ARIA live region으로 알린다.

## 검증
- 자동 검사 도구(axe)로 1차 점검
- 키보드·스크린리더 수동 테스트
- 출시 전 접근성 체크리스트 확인

## 책임
접근성은 디자이너·개발자 공동 책임이며, 디자인 시스템 컴포넌트 단계에서부터 보장한다.
